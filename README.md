# 🌤️ Vejr Dashboard

Et simpelt og smukt vejr dashboard, der viser det nuværende vejr og en 5-dages prognose for din nuværende lokalitet. **Ingen API-nøgle nødvendig!**

## 📁 Filer

- `index.html` - Hovedsiden
- `style.css` - Styling
- `script.js` - JavaScript funktioner

## 🚀 Hurtig start

### 1. Åbn dashboardet

Du kan åbne `index.html` **direkte i din browser** - ingen installation eller API-nøgle nødvendig!

Simpelt hen:
- Download eller klon repositoryet
- Åbn `index.html` i din browser (Chrome, Firefox, Safari, Edge)
- Tillad adgang til din position
- Nyd dit vejr dashboard!

### 2. (Valgfrit) Host på en webserver

Du kan også hoste filerne på enhver webserver (GitHub Pages, Netlify, Vercel, etc.)

## 🌍 Funktioner

- ✅ **Ingen API-nøgle nødvendig** - bruger den gratis Open-Meteo API
- ✅ Automatik positionering via browserens geolocation
- ✅ Nuværende vejr med temperatur, vejrbeskrivelse og ikon
- ✅ Dansk sprog og formatering
- ✅ Føles som temperatur
- ✅ Luftfugtighed
- ✅ Vindhastighed (km/t)
- ✅ Lufttryk
- ✅ 5-dages vejrprognose
- ✅ Responsive design (virker på mobil og desktop)
- ✅ Smukke ikoner fra Weather Icons
- ✅ Automatik opdatering hver 10. minut

## 📱 Browsersupport

- Chrome (anbefalet)
- Firefox
- Safari
- Edge
- Mobile browsers (iOS Safari, Chrome for Android)

## ⚠️ Vigtige bemærkninger

1. **Geolocation**: Browseren vil spørge om tilladelse til at bruge din position
2. **Gratis API**: Open-Meteo API er gratis og kræver ingen registrering
3. **Privacy**: Din position bruges kun til at hente vejrdata og gemmes ikke
4. **Offline**: Dashboardet virker ikke offline - kræver internetforbindelse

## 🎨 Tilpasning

Du kan nemt tilpasse:
- Farver i `style.css`
- Layout og design
- Hvilke vejrdata der vises
- Opdateringsinterval (ændre `setInterval` i script.js)
